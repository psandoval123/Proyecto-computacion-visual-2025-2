# EyeTrack-Ads 👁️

**Estado del Proyecto:** 🚧 En Desarrollo Activo

Sistema de análisis de audiencia para publicidad digital mediante visión por computadora. El objetivo final es procesar video en tiempo real para medir el engagement through de personas, tracking y estimación de mirada.

## 📋 Descripción

Este proyecto es parte de nuestro trabajo para la materia de Computación Visual. Busca desarrollar un prototipo funcional que:

*   Detecte y cuente personas frente a una pantalla.
*   Estime el tiempo de atención.
*   Intente determinar la dirección de la mirada.

## 🛠️ Stack Tecnológico Previsto

*   **Lenguaje:** Python
*   **Librerías:** OpenCV, PyTorch o TensorFlow, MediaPipe/Dlib.
*   **Modelos:** YOLO (para detección), DeepSORT (para tracking).
